MODAL

Modal.

Modal is a UI component that displays a dialog box or popup over the main content of a webpage. It is used to display important information, such as messages, forms, or alerts, that requires the user's attention.

Class names

Start with modal, then add modifiers when needed.

Class name Description
modal Normal modal
modal-window A modal window
modal-content Modal content section

Grids

Grids.

The Grid system allows you to easily create responsive layouts. You can control the number of columns, the gutter (gap) between columns, and the alignment of the content. It's built on top of CSS Grid and Flexbox, providing a robust and flexible way to structure your web pages.

Class names

Start with grid, then add modifiers when needed.

Class name Description
grids Main grids tag in div
grid Grid item in div
grids-3 Grid with 3 columns
grids-4 Grid with 4 columns
grids-5 Grid with 5 columns

BUTTONS

Buttons.

Buttons let people take clear actions. Use a primary button for the most important action in a section.

Class names

Start with btn, then add modifiers when needed.

Class name Description
btn The base button class.
btn-one A small radius button
btn-outline A button with an outline
btn-large A large button
btn-wide A button with large width

Button sizes

Choose a size that fits the density and priority of your interface.

Code 
<button class="btn-outline"><a href="#">Button outline</a></button>
<button class="btn-large"><a href="#">Button large</a></button>
<button class="btn-wide"><a href="#">Button wide</a></button>

Customizable button

You can change the color of the button and the text of the button.

Code 
<button style="background-color: rgb(255, 0, 0);" class="btn"><a style="color: rgb(255, 255, 255);"
href="#">Button</a></button>

Custom hover effect

Create style.css file and add this code!

CSS 


.btn:hover {
    transform: translateX(3px) !important;
}
CSS 


.btn:hover {
    transform: translateY(3px) !important;
}
CSS 


.btn:hover {
    transform: scale(1.05) !important;
}

HERO

Hero section.

The hero section is the first section that appears on the screen when a user visits a website. It is used to grab the user's attention and make a good first impression. A hero section typically includes a headline, a subheadline, and a call-to-action button.

Class names

Start with hero, then add modifiers when needed.

Class name Description
hero-section Normal hero section
left-hero Left hero content
right-hero Right hero content

Get started with
NodexUI.

Install NodexUI with cdn and use all components in your project.
Latest NodexUI version : v1.0


Intall via CDN

Install NodexUI with cdn. Past this code in your Head section.

CSS 
<link rel="stylesheet" href="https://cdn.jsdelivr.net/gh/nodexui/nodexui@main/v1.0.css">

How to use?

What is NodexUI and how to use it ?

  1. First of all, Install NodexUI via CDN in your project
  2. Then, view components and past HTML code to your project
  3. Automatically apply all styles in components.
  4. Customize as per your needs and requirement.
